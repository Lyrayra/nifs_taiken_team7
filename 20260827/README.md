# NIFS CXS スペクトル解析 (2026/08/27)

LHD 荷電交換分光 (CXS) データの逆問題解析パイプライン。
観測スペクトル D(λ) から、イオンのバルク速度 v₀ と熱速度幅 dV を各チャンネルごとに抽出する。

## 解析の流れ

```
観測データ (.txt/.dat)
       │
       ▼
 forward_model.py   ← 順問題: E(λ)*I(λ) + bg のシミュレーション
       │
       ▼
 gyaku.py           ← 逆問題: curve_fit で v₀, dV, A, bg を推定
       │
       ▼
 gosa.py            ← 逆問題 + 誤差評価: pcov から dV の標準誤差を算出
       │
       ▼
 dv_r_profile.csv   ← フィッティング結果の出力
       │
       ▼
 plot_fv.py         ← R-dV プロファイルのエラーバー付きプロット
```

## スクリプト一覧

| ファイル | 説明 |
|---|---|
| `sokudobunpu.py` | ガウス型速度分布関数 f(v) の生成、速度⇔波長のドップラー変換、理論スペクトル E(λ) の計算 |
| `ilambda_builder.py` | 較正データから装置関数 I(λ) を構築。サブピクセル精度のピーク検出を含む |
| `forward_model.py` | 順問題ソルバー。理論スペクトル E(λ) と装置関数 I(λ) の畳み込みで D(λ) を計算 |
| `gyaku.py` | 逆問題ソルバー。`scipy.optimize.curve_fit` で観測データにフィッティング |
| `gosa.py` | `gyaku.py` に誤差評価を追加。共分散行列 pcov の (2,2) 成分から dV の標準誤差 (1σ) を算出 |
| `reff.py` | tsmesh データから実効マイナー半径 reff を計算。prep ファイルからチャンネル-主半径 R の対応を取得 |
| `plot_fv.py` | R-dV プロファイルをエラーバー付きで描画 |

## データファイル

| ファイル | 説明 |
|---|---|
| `a260825_img.txt` | 較正画像データ（装置関数 I(λ) の構築に使用） |
| `lhdcxs9a_img_sig@189129_t4.44s.txt` | 観測スペクトルデータ D(λ)（ショット #189129, t=4.44s） |
| `lhdcxs9a_prep@189129.dat` | prep ファイル（チャンネルと観測位置 R の対応表） |
| `tsmesh@189129_t4.44s_phi18deg.dat` | トムソン散乱メッシュデータ（reff 計算用） |
| `dv_r_profile.csv` | フィッティング結果の出力 CSV（R, v₀, dV, dV_err, A） |

## 実行方法

```bash
# 1. 逆問題を解いてフィッティング（誤差なし）
python gyaku.py

# 2. 逆問題を解いてフィッティング（誤差評価付き）
python gosa.py

# 3. R-dV プロファイルの描画
python plot_fv.py
```

## 依存ライブラリ

- `numpy`
- `scipy`
- `matplotlib`

## モデル

フィッティングモデルは以下の4パラメータ:

| パラメータ | 記号 | 単位 | 説明 |
|---|---|---|---|
| 振幅 | A | - | 輝線の強度係数 |
| バルク速度 | v₀ | m/s | イオンの流れ速度 |
| 熱速度幅 | dV | m/s | ガウス分布の幅（イオン温度に対応） |
| バックグラウンド | bg | counts | 連続光などのバックグラウンド |

誤差評価は `curve_fit` が返す共分散行列 `pcov` の対角成分から算出:

```
dV_err = √(pcov[2, 2])   ← dV の標準誤差 (1σ)
```

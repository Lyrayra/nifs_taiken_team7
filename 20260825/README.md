# 分光器スペクトルデータ解析プログラム群

このディレクトリには、分光器から取得したスペクトルデータを解析・可視化し、理論的な速度分布モデルとの比較や畳み込み計算を行うためのPythonプログラムが含まれています。

## データファイルについて
* **a260825_img.txt / aim260825_img.txt**
  分光器の結果を保存したスペクトルデータのファイルです。

## プログラム一覧と解説

* **taka.py**
  分光器のデータファイルを読み込み、指定した特定のフレームにおける2次元スペクトルのヒートマップを描画するプログラムです。ピクセルから波長への一次関数フィッティング（キャリブレーション）を行い、正しく波長軸を合わせて表示します。

* **takaave.py**
  全フレームのデータを読み込み、波長キャリブレーションを行った上で以下の2つを描画します。
  1. 全フレームの平均をとった2次元ヒートマップ
  2. 空間方向（y軸）および全フレームで平均化した1次元の平均スペクトル（折れ線グラフ）
  全体的なスペクトルの形状やベースライン（バックグラウンド）の確認に用います。

* **takaapart.py**
  平均化されたスペクトルデータから、特定の波長ピーク（529.82 nm付近と530.48 nm付近など）の周辺領域のみを切り出し、ベースライン補正および正規化を行って並べて表示するプログラムです。特定の輝線の詳細なプロファイルを比較・確認するのに適しています。

* **sokudobunpu.py**
  ガウス型の理論的な速度分布関数（マクスウェル分布）を計算し、ドップラー効果の式を用いて波長分布（理論スペクトル $E(\lambda)$）へと変換するプログラムです。実測された平均スペクトルと理論的なスペクトルを重ね合わせてプロットし、波長軸上での形状の違いを比較できます。

* **ilambda_builder.py**
  実測された平均スペクトルデータから、バックグラウンド成分を差し引き、面積で正規化し、ピークが中心にくるように配列をシフトさせた「装置関数（Instrumental Function, $I(\lambda)$）」を構築するプログラムです。生成されたデータは `I_lambda.npz` として保存されます。

* **convolve_elambda_ilambda.py**
  `sokudobunpu.py` に基づく理論的な発光スペクトル $E(\lambda)$ と、`ilambda_builder.py` で作成された装置関数 $I(\lambda)$ を波長空間で畳み込み（コンボリューション）計算するメインプログラムです。畳み込み結果を描画し、結果を `convolution_result.npz` に保存します。

## 順問題の計算ロジックと現在の実装状況

現在、観測されるスペクトル $M(\lambda)$ をモデル化する「順問題」の計算は、以下のような物理モデルとプロセスで実装されています。

### 1. 理論スペクトル $E(\lambda)$ の計算 (`sokudobunpu.py`)
プラズマやガスの物理パラメータとして**バルク速度 $v_0$** と **熱速度の広がり $dv$** を与え、理論的な速度分布（ガウス分布）を計算します。
その後、ドップラーシフトの式 $v = c \frac{\lambda - \lambda_0}{\lambda_0}$ を用いて速度を波長 $\lambda$ に変換し、ヤコビアンを掛けることで波長空間での理論的な発光スペクトル $E(\lambda)$ を生成します。

### 2. 装置関数 $I(\lambda)$ の抽出 (`ilambda_builder.py`)
実測データから、分光器自身のボケやにじみを表す装置関数 $I(\lambda)$ を抽出します。バックグラウンドを除去し、面積で正規化し、配列の中心にピークが来るように調整して `I_lambda.npz` に保存します。

### 3. 波長空間での畳み込み計算 (`convolve_elambda_ilambda.py`)
物理パラメータ $v_0, dv$ から求めた $E(\lambda)$ と、実測から求めた $I(\lambda)$ を**波長空間（$\lambda$）のまま畳み込み（コンボリューション）**します。
$$ D(\lambda) = E(\lambda) * I(\lambda) $$
計算は波長軸上で行われるため、補間などによる誤差を抑えつつ正確な畳み込み結果 $D(\lambda)$ が得られます。

### 現在できていること・今後の課題
* **【完了】** $v_0$ と $dv$ をパラメータとして与え、波長空間での理論スペクトル $E(\lambda)$ を正確に導出すること。
* **【完了】** 装置関数 $I(\lambda)$ の抽出と、波長空間での $E(\lambda) * I(\lambda)$ の畳み込み計算。
* **【未完了・Next Step】** 畳み込みで得られたモデルスペクトル $D(\lambda)$ を、**「実際の実測データ $M(\lambda)$」と波長軸上で直接重ね合わせて比較する機能**（現在は理論式同士の畳み込み結果をプロットする部分まで実装済）。
* **【未完了・Next Step】** 順問題の比較結果をもとに、$D(\lambda)$ と $M(\lambda)$ の誤差が最小になるような最適な $v_0, dv$ を自動探索するフィッティング（逆問題の求解）の実装。
